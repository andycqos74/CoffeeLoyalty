Google Wallet

Setup instructions (takes ~10 minutes, free)
  1. Go to pay.google.com/business/console and sign up as a Google Wallet issuer (free). Copy your Issuer ID (a long number).
  2. Open console.cloud.google.com → pick or create a project → search for “Google Wallet API” and enable it.
  3. Go to IAM & Admin → Service Accounts → Create a service account.
  4. Grant it the role “Wallet Object Issuer”.
  5. Click the service account → Keys → Add Key → Create new key → JSON. Download the file.
  6. Back in the Wallet console, go to Business → Users and add the service account email with Developer access.
  7. Paste the Issuer ID and the full contents of the JSON file above and save.
  8. The first earn on any customer's card will auto-create the LoyaltyClass and push a “Save to Google Wallet” link to their card.
